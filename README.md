## What I'm up to

I just finished building a custom charger dock for batteries at my school.
The official dock works maybe 20% of the time, so I reverse engineered the
proprietary connector, modeled a replacement in Onshape, and printed it.
It works. The original doesn't.

Before that: CTF on Root Me and PortSwigger. Currently picking up Assembly
and C/C++ because Python feels too comfortable.

## Other things I've done

- Bypassed restrictions on ~30 school Unowhy laptops. Adapted a known
  technique, it now runs better than intended.
- Learned breadboarding the hard way (the magic smoke escaped a few times).
